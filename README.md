# Контрольная точка #4

В этой контрольной точке требуется реализовать базовый функционал админпанели:
- отображение данных в табличном виде;
- добавление записи через форму;
- редактирование записи через отдельную форму либо редактируемую таблицу;
- удаление записи с подтверждением;
- всплывающие уведомления.

Реализуйте задание на нескольких стеках по вашему выбору:

- `react hook form` + `mantine`;
- `antd`;
- `tanstack table` + `tanstack form` + `shadcn/baseui`.

_Максимальный балл: 30_

## Требования и критерии оценивания

### `react hook form` + `mantine` (до 14 баллов)

#### Отображение данных (до 2 баллов)

Выведите все имеющиеся данные используя компонент `mantine table`. Настройте отрисовку полей с датой в формате дд.мм.гггг (1 балл). Поиск, сортировка, пагинация и фильтрация не требуются.

#### Добавление записи (до 6 баллов)

Создайте форму для добавления данных согласно макету, используя `react hook form` и подходящие компоненты `mantine`. Форма помещена в модальное окно, открывается при клике на соответствующую кнопку. Настройте валидацию через `zod` и отображение ошибок. Сохраняйте данные в память. (4 балла)

По возможности, реализуйте пошаговый ввод данных (2 балла).

#### Редактирование записи (до 2 баллов)

На основе предыдущей формы реализуйте аналогичную, предзаполненную имеющимися значениями. Форма размещена в модальном окне, открывается при клике на иконку редактирования в строке таблицы. Сохраняйте изменения в память. Переиспользуйте валидацию, пошаговость - опциональная.

#### Удаление записи (до 2 баллов)

Реализуйте удаление записи при клике на иконку удаления в строке таблицы. (1 балл) 

Добавьте этап подтверждения удаления, используя подходящие компоненты `mantine`. (1 балл)

#### Уведомления (до 2 баллов)

Отображайте уведомления при успешном удалении, создании и редактировании записей. Используйте подходящие компоненты и хуки `mantine`.

### `antd` (до 18 баллов)

#### Отображение данных (до 7 баллов)

- выведите все имеющиеся данные используя компонент `antd table` (1 балл);

- настройте отрисовку полей с датой в формате дд.мм.гггг (1 балл);

- реализуйте поиск по одному из полей (1 балл);

- реализуйте сортировку по одному из строковых полей (1 балл);

- реализуйте сортировку по одному из полей c датой или временем (1 балл);

- реализуйте фильтрацию по любому подходящему полю (1 балл).

- реализуйте клиентскую пагинацию (1 балл). 

#### Добавление записи (до 3 баллов)

Создайте форму для добавления данных согласно макету, используя `antd form` и подходящие компоненты `antd`. Форма размещена в компоненте `antd drawer`, открывается по клику на соответствующую кнопку. Настройте валидацию и отображение ошибок. Сохраняйте данные в память. Пошаговый ввод данных не требуется.

#### Редактирование записи (до 5 баллов)

На основе предыдущей формы реализуйте аналогичную, предзаполненную имеющимися значениями. Сохраняйте изменения в память. Переиспользуйте валидацию, пошаговость не требуется. (3 балла)

Форма размещена в компоненте `antd drawer` _либо_ в редактируемой строке (+2 балла).  Редактирование, сохранение и отмена изменений происходят по клику на соответствующие кнопки (либо иконки в строках таблицы). 

#### Удаление записи (до 2 баллов)

Реализуйте удаление записи при клике на иконку удаления в строке таблицы. (1 балл) 

Добавьте этап подтверждения удаления, используя подходящие компоненты `antd`. (1 балл)

#### Уведомления (1 балл)

Отображайте уведомления при успешном удалении, создании и редактировании записей. Используйте подходящие компоненты `antd`.
